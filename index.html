Flick (Android)

Designer/Engineer: Matthew Pool

Synopsis & Engineering

Flick is a native Android streaming client designed to deliver a massive, instant content library. By leveraging the Archive.org API, the architecture bypasses traditional licensing hurdles and reduces backend content delivery costs to near-zero. The result is a highly scalable, business-viable product continuously deployed through a vigorously tested CI/CD pipeline.

Architecture: Taking ownership of the entire product lifecycle—from early Figma prototypes to Google Play closed testing—I engineered the full stack using Kotlin, Jetpack Compose, and MVVM architecture. I built a custom recommendation engine from scratch, integrating async preloading for seamless, low-latency playback. Under the hood, Flick tokenizes video metadata and weighs it against user interaction signals (view time, likes/dislikes) stored in Firestore to generate dynamic user profile vectors.

Algorithm: The core recommendation engine relies on cosine similarity to calculate the exact distance between user profiles and available content. To prevent content echo chambers, the main vertical feed employs an "exploration vs. exploitation" strategy, strategically balancing high-confidence matches with randomized, high-percentile videos.

UI/UX: The interface features an intuitive, dual-axis navigation system driven directly by the underlying ML algorithm. A vertical swipe continues the mixed discovery feed, while a horizontal swipe instantly branches into a "nearest neighbor" playlist—curating a continuous stream of videos with the highest cosine similarity to the current selection.
